### 移动端与画面

- 加入触屏摇杆、梯子攀爬和水中上下移动。
- 加入背景墙、头部晃动、视差背景、昼夜优化和全新 UI。
- 加入沙子、水、空桶、水桶以及取水和倒水操作。

### 方块与物品

- 加入锤子、锄头、门、楼梯、梯子和不同材质的装备。
- 加入玻璃、苹果和耕地，并支持工作台及木门交互。

### 文档

- 添加以英文为默认语言的 README 文档。
- 添加简体中文 README，并提供双向语言导航。
- 记录原始版本号与规范化版本号、已知功能、限制和归档状态。
- 为本次 Release 添加独立且内容完整的简体中文更新日志。
- 记录此历史标签实际采用的最终归档源码快照。
- 记录 FlatMC 已由 FlatCraft 取代。

### 已知限制

- 尚无死亡掉落、食物、创造模式、僵尸、命令和多人联机。
- 锄头、盔甲和部分方块尚未完成全部功能。
- iOS 和 PC 版本尚未同步。
- 此 Release 对应的原始源码提交和可验证原始二进制文件尚未恢复。
- GitHub 自动生成的源码压缩包实际代表 FlatMC Unity Edition 最终归档源码快照，并非重建的 `v0.1.0` 源码树。
- 不保证历史存档、网络协议及构建与 FlatCraft 兼容。
