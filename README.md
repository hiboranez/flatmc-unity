> [!IMPORTANT]
> FlatMC Unity Alpha is no longer developed or maintained. FlatMC has been succeeded by **FlatCraft**. This repository is preserved as a historical record and is not guaranteed to be compatible with FlatCraft.

## Overview

FlatMC Unity Alpha was a mobile-focused Unity rewrite of FlatMC. It introduced touch controls, layered backgrounds, water, lighting, storage, smelting, hunger, armor, and a three-dimensional player model. Development later moved to Godot.

The first normalized GitHub release is `0.1.0`. The later historical release will be published after review.

## 0.1.0 Features

- Android APK with touch joystick controls.
- Background walls, head movement, parallax backgrounds, improved day/night rendering, and a redesigned UI.
- Sand, water, empty and filled buckets.
- Hammers, hoes, doors, stairs, ladders, armor items, glass, apples, and farmland.
- Ladder climbing, swimming controls, water collection, workbench interaction, and doors.

This early build did not yet include several planned systems, including creative mode, zombies, commands, multiplayer, food, functional armor, and complete death drops.

## Technology Stack

- Unity 2022.3 LTS
- C#
- Universal Render Pipeline
- Android and experimental desktop targets

## Known Limitations

- The repository is a later preservation snapshot, not a reconstructed `0.1.0` source tree.
- No original, verifiable `0.1.0` APK is currently attached.
- iOS support was not completed.
- The project is not compatible with FlatCraft.
## Project Status

**Archived / Superseded**

Development ended after the original Unity beta. FlatCraft is the successor to FlatMC.
